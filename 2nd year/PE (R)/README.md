# 📊 Advanced Statistical Analysis & Data Visualization with R - Probability and Statistics

## 📋 Project Overview
This repository contains the resolution of a set of 10 practical problems focused on **Data Analysis**, **Statistical Visualization**, and **Stochastic Simulation**. The project was developed using the **R** language, relying heavily on the **ggplot2** ecosystem and advanced **Statistical Computing** techniques.

## ✨ Key Features
- 📈 **Advanced Visualization**: Complex plots with `ggplot2`, including parallel boxplots with outlier handling, comparative bar charts, and time series with daily moving metrics.
- 🎲 **Monte Carlo Simulations**: Implementation of simulations to calculate expected values, verification of historical probability paradoxes (such as the Grand Duke of Tuscany's dice problem), and demonstration of the Central Limit Theorem.
- 🧬 **Probability Distributions**: Modeling and manipulation of Weibull, Irwin-Hall, Rayleigh, and Exponential distributions.
- 🔍 **Statistical Inference**: Calculation of Maximum Likelihood Estimates (MLE) using numerical methods (`uniroot`), Hypothesis Testing, and Confidence Intervals.
- 🧪 **Goodness-of-Fit**: Implementation of the Chi-Square test to validate the fit of theoretical models to real-world wind speed data.
- 🏗️ **Data Wrangling**: Cleaning and filtering of real datasets using conditional logic and data type manipulation (Dates, Factors, etc.).
- 🏆 Achieved a grade of **19.00/20**

## 📌 Core Functionalities
The project addresses the following fundamental areas:
1. **Exploratory Data Analysis (EDA)**: Variable transformation (square root) and dispersion analysis in viticultural and climatic data.
2. **Stochastic Simulation**: Generation of random samples with fixed seeds to ensure reproducibility (`set.seed`).
3. **Estimation Theory**: Numerical resolution of parameters where no explicit analytical solution exists.
4. **Hypothesis Testing**: Calculation of test power and estimation of Type II Error probability ($\beta$).
5. **Distribution Fitting**: Support division into equiprobable classes for adherence testing.

## 📂 Project Structure
The file organization reflects the competencies demonstrated:
- 📁 **Graphics_Scripts/**: R code for visualization challenges (`winequality`, `wine_prod_EU`, `clima.csv`).
- 📁 **Probability_Simulations/**: Scripts focused on Weibull, Irwin-Hall, and data simulation.
- 📁 **Inference_Tests/**: Implementations of MLE, Confidence Intervals, and Chi-Square tests.
- 📄 **Final_Reports/**: Formatted PDF files containing the source code and generated graphical outputs.
